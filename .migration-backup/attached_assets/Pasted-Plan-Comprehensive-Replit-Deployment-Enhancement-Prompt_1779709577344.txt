 Section 7: RAG + Reply Enhancement

 1. Hybrid search: Already implemented (retrieval.py). Ensure ENABLE_HYBRID=true in env.
 2. Better system prompt: Rewrite to be more conversational, first-person, bilingual-aware
 3. Confidence calibration: Lower threshold to 0.35 for Arabic (Arabic embeddings score lower)
 4. Answer length control: Add max_tokens=300 for short factual answers, 700 for detailed
 5. Citation mode: Append source document name to answers: "Based on [document name]..."
 6. Rejection phrase detection: Add more Arabic rejection phrases to _is_no_answer() check
 7. Context window: Increase MEMORY_WINDOW to 10 for better multi-turn coherence
 8. Chunk dedup: Before generation, deduplicate overlapping chunks from same document

 Section 8: Handoff Feedback Enhancement

 1. Delivery confirmation: Track delivery status in Handoff.delivery_status column
 (pending/sent/failed)
 2. Retry queue: Add background task to retry failed deliveries every 60s (max 3 attempts)
 3. Agent reply threading: Show agent replies inline in handoff chat as "Agent: {name}"
 4. Handoff resolution feedback: After resolving, prompt admin "Was this resolved satisfactorily?"
 (Y/N) — store in Handoff.resolved_satisfactorily
 5. Customer satisfaction: After resolution, send customer a 1-5 star rating prompt on their channel
 6. Handoff SLA: Show time-in-queue in handoffs list; highlight red if > 1 hour unresponded
 7. KB teaching shortcut: In handoff view, one-click "Use bot reply as answer" without re-typing
